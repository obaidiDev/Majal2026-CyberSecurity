HTTP is stateless — the cookie is the only memory

The server forgets you between requests. So at login it hands you a session cookie and writes it in a table. Every later request just says “here's my cookie” — whoever holds it is that user.

① Your browser sends this cookie
Cookie: session=
a long random value — you could never guess someone else's
try ↓
GET /account
② The server's session table
The server looks up whatever cookie arrives. It has no other way of knowing who you are.
